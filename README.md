# Timing-Driven VLSI Router

A C++-based educational VLSI routing project that integrates static timing analysis with physical design to prioritize timing-critical connections.

The project reads structural Verilog, LEF cell geometry, placement information, and critical-net data generated by a separate Python Static Timing Analyzer (STA).

## Project Overview

Physical routing connects the pins of placed standard cells while respecting geometric constraints. Routing decisions can affect wire length, congestion, and ultimately circuit timing.

This project aims to develop a timing-driven grid router that prioritizes critical signal paths before routing less timing-sensitive connections.

## Current Features

- **Structural Verilog Parsing:** Extracts standard-cell instances, pin connections, and net connectivity.
- **LEF Parsing:** Reads cell dimensions and pin geometry.
- **Placement Processing:** Loads standard-cell coordinates from a placement file.
- **Grid Representation:** Models the chip as a 2D grid containing placed cells and routing obstacles.
- **Pin Access Generation:** Calculates routing access coordinates for standard-cell pins.
- **Net Grouping:** Identifies the pins belonging to each electrical net.
- **STA Integration:** Imports critical-net information generated by a separate Python STA project.

## Planned Features

## How It Works

1. Parse structural Verilog to identify instances and connected nets.
2. Read LEF definitions to obtain cell dimensions and pin positions.
3. Load placement coordinates and calculate absolute pin locations.
4. Represent standard-cell footprints as blocked regions on a routing grid.
5. Generate accessible routing points for each cell pin.
6. Import timing-critical net names from the Python STA.
7. Use the resulting connectivity, geometry, and timing information as the foundation for timing-driven routing.
